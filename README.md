📋 Genel Bakış  
Bu Spring Boot uygulaması, doğrulama ve hata yönetimi özellikleriyle kullanıcı yönetimi için RESTful API sağlar. Her alan için uygun doğrulama kurallarıyla kullanıcı verilerini oluşturmanıza ve almanıza olanak tanır.

🔍 Özellikler  
Kullanıcı Yönetimi: Kullanıcı bilgilerini oluşturma ve getirme  
Girdi Doğrulama: Jakarta Bean Validation kullanarak kapsamlı alan doğrulaması  
Hata Yönetimi: Anlamlı hata mesajları ile global hata işleme  
Sıralama Özellikleri: Kullanıcıları yaşa göre artan/azalan şekilde listeleme  
REST Mimarisi: Temiz RESTful API tasarımı  
Veri Haritalama: MapStruct ile ayrı DTO, entity ve resource yapıları  

🛠️ Teknolojiler  
Spring Boot: Üretime hazır uygulamalar oluşturmak için framework  
Spring Data JPA: Hibernate ile veri erişim katmanı  
Lombok: Tekrarlayan kod miktarını azaltır  
MapStruct: Tip güvenli bean haritalama  
H2 Database: Bellek içi veritabanı (yapılandırılabilir)  
Jakarta Bean Validation: Alan doğrulama
